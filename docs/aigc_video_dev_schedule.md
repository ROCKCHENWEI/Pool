## 2. 里程碑

1. M1（2026-03-24）：最小闭环可跑。
2. M2（2026-04-14）：稳定性达标，可内部持续使用。
3. M3（2026-05-05）：Beta 可对外试用。

## 3. 角色与资源建议（最小配置）

1. Rust Core（1 人）：引擎、DB、Provider、FFI。
2. macOS（1 人）：SwiftUI、任务面板、配置页。
3. 测试/运维（0.5 人）：测试用例、环境、发布流程。

## 4. W1 立即执行清单（2026-03-11 ~ 2026-03-17）

1. 修复 `ffi/swift.rs` 与 `models/shot.rs`、`models/workflow.rs` 构造函数参数不一致。
2. 补齐 Rust 工具链（`cargo`）并建立一键脚本：`build/test/run`。
3. 输出《最小闭环技术方案》1 页：节点输入输出、状态机、错误处理。

## 5. 风险与依赖

1. 外部 API（如 Kling）状态与配额限制可能影响联调进度。
2. 本地 ComfyUI 环境搭建复杂度可能导致 W5 波动。
3. 当前仓库仍处早期骨架，需优先保障“闭环先行”，避免并行过多特性。

## 6. 排期执行规则

1. 每周固定一次里程碑评审（建议周一），核对目标偏差。
2. 每天同步阻塞项与风险，超过 24 小时阻塞必须升级处理。
3. 任何新增需求先评估对 M1/M2/M3 的影响，再决定是否进入当前迭代。
